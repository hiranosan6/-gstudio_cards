# ルール札の定義

> **状態**: 設計中
> **作成者**: ユーザー＋Claude
> **最終更新日**: 2026-11-23
> **関わる柱**: 柱1「札で考える」、柱3「壊れても遊べる」

## Overview(概要)

ルール札は、トランプ遊びのルールを「配り方・手番の行動・出せる条件・場の流れ・上がり条件」の5つの分類に分けた部品である。
遊び手はこの札をルール盤に並べて、自分のルールを組み立てる。
この仕組みは、札1枚ごとの名前・説明・分類・記号・調整できる値(札の上の小さなつまみ)・相性(一緒にあるとよい札、両立しない札)を定める。
最小構成は、試作(`prototypes/rule-engine/REPORT.md`)で大富豪・7ならべ・ババ抜きの再現を確かめた16枚とする。
札が実際に何を起こすか(振る舞い)は、ルールの実行部分(仕組み4)が受け持つ。

## Player Fantasy(遊び手の体験)

- **直接の体験**: 札を手に取った瞬間に「これを入れたら何が起きるか」が想像できる。「パス[3]回で負け」のつまみを回して、遊びの手触りが変わるのを楽しめる。
- **間接の体験**: 大富豪は10枚、7ならべは8枚、ババ抜きは6枚の札でできていると気づく。「ルールは部品でできている」という発見が、自分で作る意欲につながる(柱1「札で考える」)。

## Detailed Design(詳細な決まり)

### Core Rules(基本の決まり)

1. 札1枚は次の項目を持つ。

| 項目 | 内容 |
| ---- | ---- |
| 識別名 | 英字の snake_case。一度決めたら変えない(保存したルールが参照するため) |
| 名前 | 8文字以内 |
| 説明 | 20文字以内 |
| 分類 | 配り方/手番の行動/出せる条件/場の流れ/上がり条件 のどれか1つ |
| 記号 | 分類の記号(扇・手・鍵・輪の矢印・旗。`design/art/art-bible.md` 4章) |
| 絵柄 | 図にしたアイコン |
| 調整値 | 0個か1個。名前・既定値・最小・最大・表示の形(例: 「パス[3]回で負け」)を持つ |
| 一緒にあるとよい札 | 識別名の一覧 |
| 両立しない札 | 識別名の一覧 |
| 段階 | 最小構成/特殊札 |
| 最初から使えるか | はい/いいえ(いいえは開放が必要) |

2. 同じ札は、1つのルールに1枚までしか置けない。
3. 札の意味は「置かれているかどうか」と「調整値」だけで決まる。置く順番や位置で意味は変わらない。
4. 相性の悪い組み合わせでも置くことはできる。ルール盤は注意を出すだけで、禁止しない(柱3「壊れても遊べる」)。
5. トランプには強さを持たせない。強さは「出せる条件」の札だけが決める。

#### 最小構成の16枚

| 識別名 | 分類 | 名前 | 説明 | 調整値 |
| ---- | ---- | ---- | ---- | ---- |
| `deal_all` | 配り方 | 全部配る | 山札を全員に配り切る | — |
| `add_jokers` | 配り方 | ジョーカー入り | ジョーカーを山札に入れる | 枚数 1〜2(既定 1) |
| `place_on_field` | 配り方 | 最初に並べる | 配った後、指定の数字を場に並べる | 数字 1〜13(既定 7) |
| `act_play` | 手番の行動 | 出す | 手札から場に出せる | — |
| `act_pass` | 手番の行動 | パス | 何もせずに手番を終えられる | — |
| `act_draw_from_next` | 手番の行動 | 隣から引く | 次の人の手札から1枚引く | — |
| `cond_stronger` | 出せる条件 | 強い札だけ | 場より強い札しか出せない | — |
| `cond_same_count` | 出せる条件 | 同じ枚数 | 同じ数字を場と同じ枚数で出す | — |
| `order_daifugo` | 出せる条件 | 2が最強 | 3が最も弱く、2が最も強い | — |
| `cond_adjacent` | 出せる条件 | 隣の数字 | 同じマークの隣の数字に出す | — |
| `flow_clear_on_all_pass` | 場の流れ | パスで流す | 全員パスで場を流す | — |
| `flow_discard_pairs` | 場の流れ | ペアを捨てる | 同じ数字2枚を自動で捨てる | — |
| `win_empty_hand` | 上がり条件 | 手札0で上がり | 手札が無くなったら上がり | — |
| `win_ranking` | 上がり条件 | 順位を付ける | 1人残るまで続けて順位を付ける | — |
| `lose_on_pass_limit` | 上がり条件 | パスで負け | パスが指定回数を超えたら負け | 回数 1〜5(既定 3) |
| `lose_holding_last` | 上がり条件 | 最後は負け | 最後まで残った人が負け | — |

既存の3ルールの組み合わせ:
- 大富豪(10枚): 全部配る・ジョーカー入り(1)・出す・パス・強い札だけ・同じ枚数・2が最強・パスで流す・手札0で上がり・順位を付ける
- 7ならべ(8枚): 全部配る・最初に並べる(7)・出す・パス・隣の数字・手札0で上がり・順位を付ける・パスで負け(3)
- ババ抜き(6枚): 全部配る・ジョーカー入り(1)・隣から引く・ペアを捨てる・手札0で上がり・最後は負け

#### 相性(試作の結果から)

| 札 | 一緒にあるとよい札 | 両立しない札 |
| ---- | ---- | ---- |
| 強い札だけ | 出す、パスで流す | 隣の数字 |
| 同じ枚数 | 出す | — |
| 2が最強 | 強い札だけ | — |
| 隣の数字 | 出す、最初に並べる | ジョーカー入り、強い札だけ |
| 隣から引く | ペアを捨てる | — |
| パスで流す | 出す | — |
| 順位を付ける | 手札0で上がり | — |
| パスで負け | パス | — |

相性は片方の札にだけ書けばよい(ルール盤が両方向に読む)。

### States and Transitions(状態と移り変わり)

| 状態 | 意味 | 次の状態 |
| ---- | ---- | ---- |
| 未開放 | 札箱に見えるが使えない | 開放されると「使える」へ(仕組み12) |
| 使える | 札箱にあり、ルール盤に置ける | 置くと「配置済み」へ |
| 配置済み | ルール盤にある。調整値を変えられる | 外すと「使える」へ |

最小構成では、すべての札が最初から「使える」状態である。札の定義そのもの(名前や相性)は遊んでいる間に変わらない。

### Interactions with Other Systems(他の仕組みとの関係)

| 相手 | 受け取るもの | 渡すもの |
| ---- | ---- | ---- |
| 1 トランプの定義 | マーク4種・数字1〜13・ジョーカー。強さは持たない(**仮の約束**。トランプの定義の設計時に確定する) | — |
| 3 ルールの形式 | — | 識別名と調整値の組 |
| 4 ルールの実行部分 | — | 識別名ごとの意味(振る舞いは実行部分が持つ) |
| 7 ルール盤 | — | 名前・説明・分類・記号・調整値の範囲・相性 |
| 9 特殊札 | — | 札を追加するときの同じ形式 |
| 12 札の開放 | 開放の状態 | 「最初から使えるか」 |
