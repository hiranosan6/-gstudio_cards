# ゲーム構想書: ルール工房(仮題)

*作成日: 2026-11-23*
*状態: 下書き*

---

## 一言で言うと

> 部品になった「ルール札」を卓に並べて自分だけのトランプ遊びを組み立て、
> ボタン1つでコンピューターと対戦して、その面白さをすぐに確かめられるシミュレーター。

---

## 基本情報

| 項目 | 内容 |
| ---- | ---- |
| **ジャンル** | ルール創作シミュレーター/トランプゲーム |
| **端末** | ブラウザ(パソコン・スマートフォン) |
| **対象** | 後述「対象とする遊び手」を参照 |
| **人数** | 1人用(自分＋コンピューター1〜5人) |
| **1回の遊びの長さ** | 1局3〜5分、1回の遊びは30〜60分 |
| **収益化** | 未定 |
| **規模の見込み** | 中(4〜6か月、1人で開発) |
| **似ている作品** | ボードゲームの試作ツール、「作って遊ぶ」系のゲーム(例: マリオメーカー) |

---

## 中心となる体験

自分が子どもの頃から遊んできた大富豪や7ならべの「うちのルール」を、自分の手で組み立てて、
すぐに卓を囲んで試せること。ルールを考える人(ゲームデザイナー)になる体験を、
トランプという誰もが知っている題材で、手軽に味わえる。

---

## 他にない特徴

「大富豪のように遊べる。**しかも**そのルールの中身を、札を並べ替えるだけで自分で書き換えられる」。
ルールが文字の設定項目ではなく、目に見える札として卓に並んでいることが、この作品の核である。

---

## 遊び手の体験の分析(MDA)

### 目指す感情

| 感情 | 優先度 | 届け方 |
| ---- | ---- | ---- |
| **表現**(創作) | 1 | ルール札の組み合わせ、名前を付けて保存 |
| **発見**(仕組みの理解) | 2 | 札1枚の違いで遊びが大きく変わることに気づく |
| **挑戦**(腕前) | 3 | 自作ルールでコンピューターに勝つ |
| **感覚**(手触り) | 4 | 札を卓に置く・配る動き、紙のトランプらしい見た目と音 |
| **くつろぎ** | 5 | 1人で気軽に試せる |
| 物語 | 対象外 | — |
| 空想(なりきり) | 対象外 | — |
| 交流 | 対象外 | 通信対戦はしない |

### 自然に生まれてほしい行動

- 大富豪を組んだあと、札を1枚だけ入れ替えて「どう変わるか」を試し始める
- 終わらないルールや一方的なルールを作ってしまい、それを直すことでルール作りの勘所を覚える
- 自分の家や地域の「ハウスルール」を再現しようとする

### 作る仕組み

1. **ルール札の卓**: 配り方・手番の行動・出せる条件・場の流れ・上がり条件を、札として並べて組む
2. **ルールの実行部分**: 並んだ札を読み取り、実際に遊べるゲームの進行に変換する
3. **どんなルールでも遊ぶコンピューター**: 出せる手の中から判断して選ぶ
4. **すぐ遊べる対戦画面**: ボタン1つで配り、対戦が始まる
5. **札の開放**: 遊んだり組んだりすると、使える札が増える(最小構成の後)

---

## 遊び手の動機

### 満たす心理的な欲求

| 欲求 | 満たし方 | 強さ |
| ---- | ---- | ---- |
| **自律**(自由な選択) | どの札をどう並べるかは完全に自由 | 中心 |
| **有能感**(上達) | 狙いどおりの遊びになるルールを作れるようになる | 補助 |
| **関係性**(つながり) | 昔遊んだトランプの記憶とのつながり | 最小限 |

### 遊び手の型(バートルの分類)

- [ ] **達成型** — 札の開放で一部に対応
- [x] **探索型** — ルールの仕組みを理解し、組み合わせを試す
- [ ] **交流型** — 対象外
- [ ] **競争型** — 対象外
- [x] **創作型**(補足) — 自分だけのルールを生み出す。主な対象

### 没入を保つ工夫

- **最初の10分**: 用意された大富豪のルールでまず1局遊ぶ → 札を1枚(例: 「8切り」)外して、もう1局遊ぶ
- **難しさの伸び方**: 札の数と種類が少しずつ増え、組み合わせの幅が広がる
- **手応えの分かりやすさ**: 変えた札の効果が、次の対戦ですぐ盤面に出る
- **失敗からの立ち直り**: 変なルールでも止まらず、一定の手数で引き分けになる。すぐ直して再挑戦できる

---

## 遊びの流れ

### 30秒の流れ
ルール札を1枚入れ替える → 「対戦」を押す → 数手打って手応えを見る。
札が卓に収まる感覚と、変えた結果がすぐ盤面に出ることが、気持ちよさの元になる。

### 5〜15分の流れ
1局(3〜5分)遊ぶ → 「強すぎた」「終わらなかった」と気づく → 札を直す。
「もう一回だけ直して試す」が繰り返しの原動力。

### 1回の遊び(30〜60分)
大富豪などを元に、自分の改造ルールを1つ仕上げ、名前を付けて保存する。保存が自然な区切り。

### 長い目で見た成長
使える札が増える(最初は基本の札 → 大富豪・7ならべ・ババ抜きを組むと特殊札が開放される、など)。
成長するのは強さではなく、表現の幅。

### また遊びたくなる理由
- **好奇心**: まだ使っていない札、試していない組み合わせ
- **積み重ね**: 名前を付けて保存した自作ルール
- **交流**: なし
- **上達**: 狙いどおりのルールを作れるようになること

---

## 柱(判断に迷ったときの基準)

### 柱1: 札で考える
ルールはすべて札として目に見え、手で並べられる。

*判断の基準*: 文字の設定項目と札のどちらで表すか迷ったら、札1枚で表せる形を選ぶ。

### 柱2: 3秒で試せる
直してから遊び始めるまでを、とにかく短くする。

*判断の基準*: 作り込んだ演出と待たずに遊べることで迷ったら、待たずに遊べることを選ぶ。

### 柱3: 壊れても遊べる
変なルールを作っても止まらず、コンピューターがそれなりに遊んでくれる。

*判断の基準*: 「この組み合わせは禁止」と止めるか遊ばせるかで迷ったら、遊ばせてみて結果で気づかせる。

### 柱4: トランプの手触り
卓・札・配る動きなど、紙のトランプらしさを大事にする。

*判断の基準*: 新しい表現と見慣れたトランプの見た目で迷ったら、見慣れたトランプの見た目を選ぶ。

柱2と柱4、柱1と柱3は、ときに引っ張り合う。この緊張関係が判断の基準として働く。

### やらないこと

- **自由記述のプログラム/スクリプトによるルール作成はしない**: 柱1「札で考える」が崩れるため
- **通信対戦はしない**: 数か月の規模に収まらず、柱2「3秒で試せる」からも外れるため
- **52枚＋ジョーカー以外の独自カードは作らない**: 柱4「トランプの手触り」が崩れ、別のジャンルになるため

## 参考にするもの

| 参考 | 取り入れること | 違うところ | 意味 |
| ---- | ---- | ---- | ---- |
| 大富豪 | 強さの順、場の流れ、特殊ルール(8切り・革命) | ルールそのものを組み替えられる | 地方ルールの多さは「ルールを作る楽しさ」の証拠 |
| 7ならべ | 場の並びに隣接して出す仕組み | 場の形も札で決められる | 「出せる条件」の違いで別の遊びになる例 |
| ババ抜き | 引く・ペアを捨てる仕組み | 「引く」行動も部品の1つにする | 手番の行動の違いで別の遊びになる例 |
| 「作って遊ぶ」系のゲーム | 作る→すぐ試す、の短い繰り返し | 題材がトランプのルール | 創作型の遊び手が存在することの裏付け |

**ゲーム以外の着想**: 家族や友人と遊んだ「うちのルール」の記憶、紙のトランプと羅紗の卓。

## 対象とする遊び手

| 項目 | 内容 |
| ---- | ---- |
| **年齢** | 20〜50代 |
| **ゲーム経験** | 中程度(ボードゲーム・カードゲーム好き) |
| **遊べる時間** | 平日の夜に30分、休日にもう少し長く |
| **よく遊ぶ端末** | パソコンのブラウザ、スマートフォン |
| **遊んでいるもの** | トランプ遊び、ボードゲーム、カードゲーム |
| **求めているもの** | 自分の考えたルールを、相手を集めずにすぐ試せる場 |
| **離れてしまう理由** | 組み立てが難しい、試すまでに時間がかかる、コンピューターが遊べずに止まる |

対象外: 対人戦で競いたい人、決まったルールで腕前を磨きたい人。

## 見た目の方向(仮)

- **方向の名前**: 羅紗の卓
- **一言の決まり**: 緑の羅紗の卓の上に、紙のトランプとルール札が置かれている見た目にする
- **補足の決まり**:
  1. ルール札はトランプより一回り大きい、色分けされた厚紙 — *判断の基準*: 札の種類は色と形で見分けられるか
  2. 動きは実物の札の動きに合わせる(配る・めくる・置く) — *判断の基準*: 実物のトランプでありえる動きか
- **色の考え方**: 卓の深い緑を土台に、ルール札の分類ごとに落ち着いた色を割り当てる。トランプ本体は白と赤黒
- 見直し頻度が最小限のため、専門役による見た目の検討は行っていない。正式には `/art-bible` で決める

## 課題と未解決の問い

### 設計の課題
- 札の組み合わせで、矛盾したルールや終わらないルールが簡単にできてしまう(柱3で受け止める)
- 札の種類が増えると、組み立てが難しくなる

### 技術の課題
- 札の組み合わせを動くゲームの進行に変換する仕組み(一番の山場)
- 未知のルールでもそれらしく打てるコンピューター(まず簡単な判断で作り、必要なら先読み型へ)

### 市場の課題
- 作るのが好きな人向けという、狭めの層であること

### 規模の課題
- 札の種類を増やすたびに、組み合わせの確認が増える

### 未解決の問い
- 約20枚の札で3つのルールを本当に再現できるか → 試作で確かめる
- 簡単な判断のコンピューターで「面白さを確かめる」のに十分か → 試作後の試し遊びで確かめる

## 最小構成

**確かめたいこと**: 「ルール札を1枚入れ替えて、すぐ対戦する」の繰り返しが、30分続けて楽しいか。

**最小構成に入れるもの**:
1. ルール札の卓(配り方・手番の行動・出せる条件・場の流れ・上がり条件)
2. 約20枚の札で、大富豪・7ならべ・ババ抜きを再現できること
3. 対戦画面(自分＋コンピューター3人、人数は2〜6人で変更可)、ボタン1つで開始
4. どんなルールでも動くコンピューター(簡単な判断)
5. 終わらないルールへの備え(一定の手数で引き分け)

**最小構成に入れないもの**(後回し):
- 札の開放
- ルールの保存と名前付け
- 対戦後の振り返り
- 自動対戦による数値の検証
- 凝った演出

### 段階ごとの規模

| 段階 | 内容 | 機能 | 目安 |
| ---- | ---- | ---- | ---- |
| **最小構成** | 札約20枚、ルール3種類 | 組み立て＋対戦 | 4〜6週 |
| **1つ通して遊べる形** | 特殊札(8切り・革命など) | 保存と名前付け、見た目の仕上げ | ＋4週 |
| **機能がそろった形** | 札約40枚 | 札の開放、対戦後の振り返り | ＋6週 |
| **完成** | 全体の仕上げ | 調整、遊び方の案内 | ＋4週 |
