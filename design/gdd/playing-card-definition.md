# トランプの定義

> **状態**: 承認済み(2026-11-23)
> **作成者**: ユーザー＋Claude
> **最終更新日**: 2026-11-23
> **関わる柱**: 柱4「トランプの手触り」

## Overview(概要)

トランプの定義は、52枚と赤・黒のジョーカーの合わせて54種類の札を定める。
札1枚が持つのはマーク・数字・色・表示名だけで、強さは持たない。強さはルール札の「出せる条件」が決める(`design/gdd/rule-card-definition.md`)。

## Player Fantasy(遊び手の体験)

間接の体験。見慣れた紙のトランプが、そのままの姿で卓に並ぶこと(柱4「トランプの手触り」)。遊び手がこの仕組みを意識することはない。

## Detailed Design(詳細な決まり)

### Core Rules(基本の決まり)

1. 札は54種類。♠♥♦♣ の各マークに A・2〜10・J・Q・K の13枚と、黒のジョーカー、赤のジョーカー。
2. 札1枚は次の項目を持つ。

| 項目 | 内容 |
| ---- | ---- |
| 識別名 | 例: `spade_01`、`heart_13`、`joker_black`、`joker_red`。一度決めたら変えない |
| マーク | ♠/♥/♦/♣(ジョーカーはなし) |
| 数字 | 1〜13(A=1、J=11、Q=12、K=13。ジョーカーはなし) |
| 色 | ♠♣と黒のジョーカーは黒、♥♦と赤のジョーカーは赤 |
| 表示名 | 例: 「♥5」「ジョーカー(黒)」 |

3. 強さは持たない。比べ方はルール札が決める。
4. 山札は52枚を基本とし、ルール札「ジョーカー入り」があればジョーカーを加える。1枚のときは黒のジョーカー、2枚のときは黒と赤の両方を入れる。
5. 使うトランプは1組だけ。2組を混ぜる遊びは扱わない。
6. ジョーカーはどの数字とも同じ扱いにならない(ペアにならず、同じ数字の組にも入らない)。
7. 赤と黒のジョーカーは見た目だけが違い、強さも働きも同じ。
8. 見た目のための並べ順は、マーク ♠→♥→♦→♣、同じマークの中は数字の順、ジョーカーは最後(黒→赤)。

### States and Transitions(状態と移り変わり)

状態はない(遊んでいる間に変わらないデータ)。表か裏か、誰に見えるかは対戦の状態(仕組み5)が受け持つ。

## Formulas(計算式)

並べ順の式は次のとおり。

`並べ順 = マークの番号 × 13 + (数字 − 1)`(黒のジョーカーは 52、赤のジョーカーは 53)

**変数:**

| 変数 | 型 | 範囲 | 意味 |
| ---- | ---- | ---- | ---- |
| マークの番号 | 整数 | 0〜3 | ♠0・♥1・♦2・♣3 |
| 数字 | 整数 | 1〜13 | A=1 … K=13 |
| 並べ順 | 整数 | 0〜53 | 小さいほど左に並ぶ |

**出力の範囲:** 0〜53。重複しない。
**例:** ♥の5は 1×13+4 = 17、♣のKは 3×13+12 = 51。

対戦中の手札は、ルールの強さの順で並べ、強さが同じときにこの並べ順を使う(対戦画面の設計で確定する)。

## Edge Cases(特殊な場合)

- **ジョーカーが0・1・2枚のとき**: 山札はそれぞれ52・53・54枚。
- **ジョーカーが3枚以上と指定されたとき**: 2枚に丸める(ルール札の定義の範囲は1〜2)。
- **4色トランプの設定のとき**: 見た目だけが変わる(♦が青、♣が緑)。色の値(赤・黒)は変わらない。

## Dependencies(依存関係)

- **依存先**: なし
- **依存元**: 2 ルール札の定義(承認済み)、4 ルールの実行部分、5 対戦の状態、9 特殊札、14 卓と札の動き、15 対戦画面

## Tuning Knobs(調整できる値)

| 値 | 既定 | 安全な範囲 | 影響 |
| ---- | ---- | ---- | ---- |
| ジョーカーの最大枚数 | 2 | 2で固定 | 赤と黒の2種類しかないため |
| マークの並べ順 | ♠♥♦♣ | 4つの並び替え | 手札の見やすさ(赤と黒が交互になる) |

## Visual/Audio Requirements(見た目と音)

- 見た目の決まり(`design/art/art-bible.md` 5章)に従う。
- ジョーカーは道化の帽子の記号を、黒と赤で描き分ける。

## UI Requirements(画面の要件)

この仕組み自体には画面の要件はない。並べ順は対戦画面(仕組み15)が使う。

## Acceptance Criteria(合格の基準)

1. 52枚がマークと数字の重複なく作られる(自動テスト)
2. ジョーカー0・1・2枚で山札が52・53・54枚になり、1枚のときは黒が入る(自動テスト)
3. ジョーカーはペアの判定・同じ数字の判定から除かれる(自動テスト)
4. 並べ順が0〜53で重複しない(自動テスト)
5. ルール札の定義の強さの式で54種類すべての強さが計算でき、赤と黒のジョーカーは同じ強さになる(自動テスト)

## Open Questions(未解決の問い)
