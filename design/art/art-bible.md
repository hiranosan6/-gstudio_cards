## 1. 一言の決まり

**「ルールは札、札は卓の上」**

ゲームの中のルールは、すべて目に見える札になっている。札はすべて、羅紗の卓の上に置かれている。
見た目の判断に迷ったら、この一言に照らして決める。

### 支える決まり

1. **紙と羅紗の質感**(柱4「トランプの手触り」)
   *判断の基準*: 光沢・発光・グラデーションと、紙の質感とわずかな影のどちらにするか迷ったら、紙の質感とわずかな影を選ぶ。
2. **札の分類は色と記号で読める**(柱1「札で考える」)
   *判断の基準*: ルール札の種類を文字で示すか、色の帯と記号で示すか迷ったら、文字を読まなくても見分けられる色の帯と記号を選ぶ。
3. **動きは実物の範囲で、短く**(柱2「3秒で試せる」)
   *判断の基準*: 動き1つは0.3秒以内。実物の札でありえる動き(配る・めくる・置く・滑らせる)以外は使わない。

## 2. 雰囲気

| 場面 | 狙う気分 | 明かり | 雰囲気を表す言葉 | 速さ |
| ---- | ---- | ---- | ---- | ---- |
| ルールを組む(工房) | 落ち着いた集中 | 卓上ランプのような暖かい光。周辺はやや暗く、卓の中央が明るい | 静か・温かい・整然 | 思索的 |
| 対戦中 | 軽い緊張と楽しさ | 全体を明るく。場の中央に光が集まる | 明快・軽快・にぎやか | テンポよく |
| 上がり・勝ち | 小さな達成感 | 上がった人の手元に、金の縁取りを一瞬だけ | 満足・すっきり | 短く(紙吹雪など派手な演出はしない) |
| 負け・引き分け | 責めない | 卓が少し暗くなるだけ。「直す」ボタンへ視線を誘う | 穏やか・次へ | 短く(柱3「壊れても遊べる」) |
| 起動・メニュー | すぐ始められる | 工房と同じ。卓に札の箱が置いてある | 親しみ・期待 | すぐ |

工房と対戦中は、明かりの明るさと光の集まり方で見分けられるようにする。

---

## 3. 形

- **トランプ**: 実物と同じ縦横比(1:1.4)。角は丸める。
- **ルール札**: トランプと同じ比率で、大きさは1.25倍。角の丸みはトランプより大きく、上部に分類の色帯と記号を置く。トランプとは大きさと角の形で見分けられる。
- **卓**: 長方形の羅紗に木の枠。卓の形は場面が変わっても変えない。
- **画面部品**: ボタンは厚紙のタグ、説明は付箋、数値の調整は木のつまみの形。画面上の部品も「卓の上の物」に見えるようにする。
- **目立たせるもの**: 場の中央と自分の手札。
- **控えめにするもの**: 他の人の手札(裏向き)、山札、捨て札。

## 4. 色

### 基本の色

| 役割 | 色 | 意味 |
| ---- | ---- | ---- |
| 卓(羅紗)の緑 | `#1F5A3D` | 土台。すべての札が映える深い緑 |
| 木枠 | `#6B4A2E` | 卓の縁と、画面部品の木の部分 |
| 紙(生成り) | `#F5F0E6` | トランプとルール札の紙の色。真っ白は使わない |
| トランプの赤 | `#B3262E` | ♥♦のマーク専用 |
| トランプの黒 | `#1E1E1E` | ♠♣のマークと文字 |
| 強調の金 | `#C9A24A` | いま選べる/選んでいる/上がり |

### ルール札の分類色と記号

| 分類 | 色 | 記号 |
| ---- | ---- | ---- |
| 配り方 | 藍 `#3B5B8C` | 扇 |
| 手番の行動 | 橙 `#C2703D` | 手 |
| 出せる条件 | 紫 `#6E4C8C` | 鍵 |
| 場の流れ | 青緑 `#2F7F7A` | 輪の矢印 |
| 上がり条件 | えんじ `#8C2F45` | 旗 |

### 色の意味の決まり

- 赤はトランプのマーク専用とし、警告には使わない。警告は橙の地に「!」の記号で表す。
- 金は「選べる・選んでいる・上がり」だけに使う。飾りには使わない。
- 画面部品の色は、卓の色(緑・木・紙)から選ぶ。分類色は、ルール札とその説明にだけ使う。

### 色の見分けにくさへの備え

- ルール札の分類は、色に加えて必ず記号で見分けられるようにする。
- トランプのマークは形で見分けられる。さらに、♦を青・♣を緑にする「4色トランプ」を設定で選べるようにする。
- 「選べる札」は、金の縁取りに加えて、札を少し持ち上げた位置で示す。
