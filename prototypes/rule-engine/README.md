# 試作: ルールの実行部分(rule-engine)

> PROTOTYPE - NOT FOR PRODUCTION。本番のコードから参照・流用しないこと。

## 確かめること
1. 約20枚のルール札(5分類の部品)の組み合わせだけで、大富豪・7ならべ・ババ抜きが最後まで動くか
2. 札をでたらめに組み合わせても、止まらずに必ず終わるか(柱3「壊れても遊べる」)
3. 簡単な判断のコンピューターで、1手0.5秒以内に収まるか

## 実行方法
Godot 4.7.1 を使い、画面なしで実行する。

```bash
godot --headless --path prototypes/rule-engine -s res://main.gd
```

結果は標準出力と `results.json` に出る。

## ファイル
- `proto_engine.gd` — 実行部分(配る・手番・出せる手の洗い出し・場の流れ・上がり判定・手数の上限)と簡単なコンピューター
- `rule_catalog.gd` — ルール札16枚と、3つのルールの組み合わせ
- `main.gd` — 3ルール×100局、でたらめな組み合わせ×1000局を対戦させて集計する
