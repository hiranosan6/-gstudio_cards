# 試作: 遊べる画面のモック(playable-mock)

> PROTOTYPE - NOT FOR PRODUCTION。本番のコードから参照・流用しないこと。
> Godot ではなく HTML で作ったのは、確認用のモックを軽く作るため(取りまとめ役の判断、2026-11-23)。

## 確かめること(仮説)

構想書 `design/gdd/game-concept.md` の中心の遊び
「ルール札を1枚入れ替える → すぐ対戦 → 手応えを見る → 直す」(柱2「3秒で試せる」)は、
実際に触って楽しいか。ユーザーが自分の手で確かめるための模型である。

## 開き方

`index.html` をブラウザで開くだけ(ファイル1枚。外部のライブラリ・書体・通信は使わない)。
スマートフォンでも開ける。

1. 工房で「大富豪」「7ならべ」「ババ抜き」のどれかを押す(ひな形が盤に並ぶ)。
2. 札箱の札を押すと盤に置き、盤の札を押すと外す。調整値は札の「−」「＋」で変える。
3. 下の金色の「対戦 ▶」を押す。自分(下)とコンピューター3人で対戦する。金の縁の札を押すと出せる。
4. 結果の「直す(工房へ)」で工房に戻り、札を入れ替えてまた対戦する。
5. 右上の隅に「直してから最初の手番まで」と「対戦ボタンから最初の手番まで」の時間(ミリ秒)が出る。

対戦中の「速さ: 速い」でコンピューターの手が速くなり、「自分もおまかせ」で自分の手もコンピューターと同じ判断で進む。

自動の確認: `node prototypes/playable-mock/check.js`(Playwright と Chromium を使う。結果は `check-results.json`、写真は `screenshots/`)

試作の進行から変えた点:
- 同じ札が2枚あれば1枚目を有効にした(試作は最後の1枚が残る不具合があった)。
- 強さはルール札の定義の式に合わせた(ジョーカーは既定14、「2が最強」なら13)。
- 手数の上限を 300手×人数 から **60手×人数(240手)** に下げた。3つのひな形を各300局回した最長が100手(大富豪91・7ならべ57・ババ抜き100)で、その2.4倍。画面の対戦で「長すぎて引き分け」まで待たせすぎないため。

## 確かめた内容(自動、33件すべて合格)

- 3つのひな形それぞれ、「おまかせ」で3局ずつすべて決着した。
- 3つのひな形それぞれ、自分の札を画面で押して最後まで進んだ(画面の誤りは0件)。
- 画面なしで各ひな形300局: すべて決着、札の総数の誤り0件。
- 相性の注意: 7ならべに「ジョーカー入り」を置くと「両立しない」の注意が橙の地と「!」で出て、札は置ける。7ならべのひな形そのものには注意が出ない。
- 保存→別のルールに変える→読み込みで、決まった形の文字列が1文字も違わず戻る。ページを開き直しても読み込める。
- 読み込みの整え: 重複は1枚目を有効、調整値の四捨五入と範囲内への丸め、文字列の "2" は既定値、知らない札は使えない札へ、壊れた文字列・新しい版・4001文字は理由付きで断る、書き出しは識別名の順。
- 結果の区別: 手番の行動が無いと「誰も動けず打ち切り」、ババ抜きから「ペアを捨てる」を外すと「長すぎて引き分け」。どちらも「直すヒント」と「直す」ボタンが出る。
- 時間: 対戦ボタンから最初の手番まで 11〜13ミリ秒(柱2の3秒に対して十分に速い)。
- スマートフォンの幅(iPhone 13 相当)で横にはみ出さない。工房の押せる部分はすべて44ピクセル以上。手札は重ねても見えている幅が44ピクセル以上。

写真: `screenshots/` の7枚(工房・注意・スマートフォンの工房・大富豪の対戦・7ならべの対戦・打ち切りの結果・決着の結果)。

## 分かったこと

- **「直す」の速さは技術の問題ではない**: 対戦の準備は十数ミリ秒で終わる。3秒の大半は、遊び手が工房で札を探して入れ替える時間になる。札箱で目的の札を見つける速さ(並べ方・絞り込み)が柱2の要になりそう。
- **最小16ピクセルと札の大きさがぶつかる**: 見た目の決まりの「文字は最小16ピクセル」を守ると、8文字の名前と20文字の説明がトランプの1.25倍の札に収まらない。この模型では名前14ピクセル・説明11ピクセルにした。本番では、説明を札の上でなくタップで出すか、札を大きくするかを決める必要がある。
- **工房と対戦では縮尺を分けた**: 工房のルール札(幅 110〜115ピクセル)と対戦のトランプ(幅 58〜64ピクセル)は同じ画面に並ばないため、それぞれの画面の中で1.25倍の比を保った。
- **7ならべの手札はマークの順の方が見やすい**: トランプの定義は「強さの順で並べる」としているが、7ならべでは同じマークがまとまっている方が出せる札を探しやすい。並べ方の場の形で切り替えた(対戦画面の設計で確定する)。
- **大富豪で上がり条件を全部外すと「打ち切り」になる**: 手札が0枚になっても上がれず、全員が自動のパスを続けるため。「長すぎて引き分け」を期待していたが、結果は打ち切り。どちらの言い方が遊び手に伝わるかは試し遊びで確かめる。
- **同じ数字を何枚で出すかの選び方**: 場が空で複数の枚数を出せるときだけ「1枚で出す」「2枚で出す」を選ばせ、それ以外は札を押すだけで出るようにした。手数が減って軽い。
- 試し遊びで確かめること: 札の名前が伝わるか、「直すヒント」が直す手がかりになるか、コンピューターの速さ(ふつう0.38秒/速い0.06秒)がちょうどよいか。
